Leave Management System

PHP, MySQL, HTML, CSS, JavaScript

A web-based Leave Management System that simplifies employee leave application, approval, and tracking with secure authentication and recovery options.

View on GitHub ↗

This system allows employees to register and log in securely, submit and view leave requests, and reset forgotten passwords using preset security questions, while administrators can manage users, update passwords, and monitor leave records efficiently.
