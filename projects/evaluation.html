Faculty Evaluation System for the Department of Computer Studies at CvSU-Imus

PHP, MySQL, HTML, CSS, JavaScript

The Faculty Evaluation System allows students to assess their instructors by answering categorized questions and leaving suggestions, helping improve teaching quality.

View on GitHub ↗

Features include a secure login for students, faculty selection excluding already evaluated members, dynamic category-based questionnaires, automated calculation of average ratings, and a comment section for suggestions.
