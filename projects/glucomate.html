GlucoMate: A Mobile Blood Glucose Monitoring App with Glucometer Reading via OCR with AI Chatbot Assistance for Individuals with Diabetes

Flutter · Dart · Firebase Authentication · Cloud Firestore · Firebase Storage · Firebase Cloud Functions · SQLite · Google Cloud Vision API · Azure Bot Service/Direct Line API · Node.js · PDF & Printing · Flutter Local Notifications

GlucoMate is a mobile blood glucose monitoring application designed to help individuals with diabetes record, track, and better understand their glucose levels. It combines convenient logging, OCR-based glucometer scanning, visual analytics, reminders, PDF reports, and AI chatbot assistance in one accessible app.

View on GitHub ↗ View Thesis Manuscript ↗

The application supports both manual and camera-based blood glucose logging, using OCR to extract readings from glucometer displays. Users can monitor trends through charts and dashboards, set personalized target ranges, receive medication or logging reminders and glucose alerts, export health records as PDF reports, and access diabetes-related guidance through an AI chatbot. Data is stored locally for offline use and synchronized with Firebase when connectivity is available.
